# Paati's Pause — downloads

The latest Paati's Pause apps for Android, Windows and macOS are attached to the [latest release](https://github.com/ragulraj-d/paatis-pause-downloads/releases/latest).

Easiest way to get them: **https://paatispause.web.app/download/** — it picks the right file for your device and explains how to install.

This repository only holds release files; they're published automatically by the app's build pipeline.
